About AlphaMarket

AlphaMarket (alphamarket.co.in) is India's premier SEBI-compliant investment advisory marketplace. Over 50 SEBI-registered advisors publish 80+ investment strategies covering Equity, F&O, Baskets, and Commodities.

The Broker Integration API enables your platform to pull these advisory signals via a secured REST API, delivering them to your trading platform and end-users seamlessly.

What You Get

  • Real-time equity BUY/SELL calls with full rationale, buy range, target, and stop loss
  • F&O positions (Futures + Options) with expiry, strike price, lots, entry/target/SL
  • Basket strategy rebalances with constituent changes
  • Trailing stop-loss updates — auto-adjusting SL by percentage, points, or fixed price
  • Live alerts: TARGET_ACHIEVED, STOPLOSS_TRIGGERED, TRAILING_SL updates
  • Call modifications and closures with exit price and P&L
  • Performance analytics: hit rate, period-wise accuracy, best/worst calls, win/loss summary
  • Full advisor context: company name, SEBI registration, profile image
  • Full strategy context: name, type, description, benchmark, CAGR, themes, volatility, horizon

Authentication & Security

All endpoints are secured with API key authentication, optional HMAC-SHA256 request signing, and IP whitelisting. Rate limiting is configurable per API key.

API Key Authentication

curl -H "x-api-key: amk_live_your_key_here" \
     https://alphamarket.co.in/api/v1/alpha/live-calls

Your API key and secret are provided during onboarding. Keep your api_secret confidential.

HMAC-SHA256 Signing (Recommended)

Signature = HMAC-SHA256(api_secret, METHOD + ":" + PATH + ":" + TIMESTAMP + ":" + BODY)

// Send as headers:
x-api-signature: <computed_signature>
x-api-timestamp: <unix_milliseconds>

Requests older than 5 minutes are automatically rejected.

IP Whitelisting

During onboarding, provide your server IP addresses. Only whitelisted IPs can access the API. Requests from other IPs receive HTTP 403.

Quick Start

Step 1: Verify Connectivity

GET /api/v1/health
Response: { "status": "ok", "version": "1.1.0" }

Step 2: Browse Advisors

GET /api/v1/alpha/advisor
GET /api/v1/alpha/advisor?theme=Equity

Returns SEBI-approved advisors with company name, registration number, themes, and strategy count.

Step 3: Browse Strategies

GET /api/v1/alpha/strategy
GET /api/v1/alpha/strategy?advisorId=<uuid>&type=Equity

Step 4: Poll Live Calls (Primary Endpoint)

GET /api/v1/alpha/live-calls              // All active calls
GET /api/v1/alpha/live-calls?type=EQUITY  // Equity only
GET /api/v1/alpha/live-calls?type=FnO     // F&O only

Poll every 30-60 seconds. Returns all active calls with the full enriched payload.

Step 5: Get Strategy Portfolio

GET /api/v1/alpha/strategy/{strategyId}/portfolio?status=ACTIVE

Step 6: Check Advisor Accuracy

GET /api/v1/alpha/strategy/{strategyId}/performance

Returns hit rate, period-wise breakdown, average return, best/worst calls, and win/loss summary.
